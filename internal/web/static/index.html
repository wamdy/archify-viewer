archify 把每次交付写到当时工作目录下的 .archify/<type>-<slug>-<YYYYMMDD-HHMMSS>/。

本工具按以下顺序找库：--root → 当前目录逐级向上找 .archify/ → config.yaml 的 roots。

archify-view list --root D:/design/.archify
archify-view gui  --root D:/design/.archify --root C:/Users/wamdy/项目/appollo/.archify

产物为 0 件时，先确认你已在该目录用 archify 交付过图；刷新不会替你生成产物。
